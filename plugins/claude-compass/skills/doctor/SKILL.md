# ClaudeCompass Doctor

Use this skill when the user asks whether ClaudeCompass, Graphify, Obsidian, token monitoring, or Claude settings are installed correctly.

Run:

```bash
plugins/claude-compass/bin/doctor.sh
```

Summarize missing pieces and give one next action per missing dependency.
