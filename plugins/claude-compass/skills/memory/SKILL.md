# ClaudeCompass Memory

Use this skill when the user asks to save project context, search memory, configure Graphify, or connect an Obsidian vault.

## Defaults

- Vault path: `~/Documents/ClaudeCompassVault`
- Session notes folder: `ClaudeCompass/Sessions`
- Decision notes folder: `ClaudeCompass/Decisions`

## Preferred Flow

1. Check Graphify with `graphify --help`.
2. Check the vault path.
3. Save concise notes in Markdown.
4. Prefer Graphify query before broad source search when the graph is initialized.
