# Product Direction

ClaudeCompass is "Claude Code Easy Mode": one connector that makes Claude more useful immediately after installation.

## Default Stack

- Memory: Graphify, Obsidian vault, `CLAUDE.md` generator.
- Visibility: token/cost statusline, `/tokens`, MCP health checks.
- Automation: session summaries, secret checks, format/test hooks.
- Workflow: GitHub, browser testing, docs lookup.
- Safety: settings backups, conservative permissions, uninstall.

## User Promise

One install gets the user to a working Claude memory system. Any unavoidable OS permissions are shown as explicit guided steps, not hidden manual research.
